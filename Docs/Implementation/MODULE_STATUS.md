composition and authority path, but it does not close every production-facing
acceptance condition: startup queue capacity, the client Loading/HUD timeline,

- Unit and Handlers remain prefab-authored MonoBehaviours.
- Reality-time Inspector values use integer milliseconds; other numeric authoring may use `float`, and authoritative Gameplay converts once to Tick/`fp`.
- Bootstrap owns Unity frame scheduling, NGO/UOS, scenes and UI; deterministic assemblies do not depend on those implementations.
- Framework runtime types remain generic; the user-requested Guinsoo equipment
  chain is the explicit formal content exception recorded by D-039.
