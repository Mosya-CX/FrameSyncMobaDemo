# ExecPlan 0135 - Camera, pointer-debug and Aatrox presentation follow-up

> Status: Complete (2026-08-13).

## Goal

Provide one formal shared client-presentation configuration for blue/red camera
views, pointer selection and outline colors; turn `CameraDebugScene` into a
small, dependency-light formal-scene analogue for pointer accuracy/performance
testing; smooth the render projection of the deterministic 30 Hz logic pose;
and finish Aatrox passive/World Ender presentation transitions.

## Constraints and decisions

- Gameplay coordinates, movement, snapshots and checksums remain unchanged.
  Render smoothing is confined to `PhysicsEntity2D.LateUpdate`, the existing
  sole Unity-root Transform writer.
- `CameraDebugScene` deliberately contains no navigation grid, pathfinding,
  Gameplay Unit, networking or battle Tick runtime. Its capsules are lightweight
  presentation proxies.
- The pointer harness reuses `MouseWorldResolver` for the formal screen-ray to
  mathematical-ground-plane conversion and fixed-point center-radius selection
  semantics. Proxy stable IDs stand in for UnitUid after all proxies share one
  neutral test kind.
- Blue and red cameras use one asset with opposite yaw/follow offsets. The same
  asset owns ground height, pick radius, ally/enemy outline colors, outline
  width, VSync and render-pose smoothing.
- Aatrox-specific names remain in content/editor setup and tests. Runtime exit
  signaling is the generic optional `AnimationVariantExit` profile trigger.
- Outline pose baking executes after generic Buff-driven bone visibility, so
  hidden wings cannot remain in the generated outline mesh.

## Implementation

- Added `MobaCameraPresentationConfig`, consumed by `CameraController`, formal
  pointer binding and the formal hover-outline driver.
- Added client-only `PhysicsPresentationSettings` and interpolation of the
  authoritative previous/current render target in `PhysicsEntity2D.LateUpdate`.
- Added `CameraDebugWorkbench`, `CameraDebugPointerProbe` and lightweight stable
  proxies. Runtime overlay reports candidates, ground/screen error, last/average/
  peak detection microseconds and outline-switch microseconds; the cyan ring is
  the current selection radius.
- Added Inspector buttons to switch side, apply the draft to formal config,
  pull formal values, and generate/remove 128/512-proxy stress sets.
- Added an Editor setup command that wires the formal config to `GameScene` and
  creates the saved simplified test-scene composition.
- Added `AatroxULTOut`, transition routing on World Ender end, longer passive
  locomotion blends and longer empowered-attack entry blending.
