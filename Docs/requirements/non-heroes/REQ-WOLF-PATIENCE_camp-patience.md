# 营地共享耐心与越界恢复

## 目标实现

越过 650 作者单位时迅速消耗共享营地耐心，不因任一小狼短暂跨线就立即全营重置。

## 技术方案

Greater 主怪活着时用其位置作为 leash 权威，死后使用最远存活成员。6.5 逻辑单位越界开始快速流失耐心；进入更小恢复半径才恢复，另设更远 absolute reset 半径。耐心归 JungleCamp，member slot 保持稳定身份。

## 边界情况

主怪死亡、小怪瞬时跨界、目标失效、耐心耗尽、最远成员并列、回营期间受攻击与极远位置分别明确。恢复半径、耗尽率、最大值和绝对重置半径在继续执行时需按已有作者配置核实；原计划未给最终数值，不能自造。

JungleCampSnapshot 保存影响未来结果的耐心状态，checksum 同步；GameplaySnapshot 源码目前为 25，而旧已验证动作身份修订为 24，本期按未完成计划的实际差异登记，未经核对不能声称 schema 25 已验收。

## 验收条件

范围内不掉耐心，越界快速流失；主怪活着选主怪，死后选最远成员；滞环恢复和极远强制 reset 正确；Snapshot/Restore/Replay 等价，耐心变化可被 checksum 检测。

## 附录

旧行为曾为任一存活成员越过 hard leash 即重置，本功能已要求用共享耐心替代。资源和 Gizmo 应显示独立耗损、恢复与绝对重置圈。
