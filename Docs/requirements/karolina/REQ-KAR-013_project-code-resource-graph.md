# 工程代码与 Unity 资源关系图谱

## 目标实现

Karolina 为当前 Unity 工程建立可搜索、可追溯的 CodeGraph 与 ResourceGraph。用户可从脚本、类型或 Unity 资源进入，查看与其相连的代码和资源，并可将图谱节点作为 Agent 上下文入口。图谱是工程事实索引，不是架构设计或执行权限系统。

## 技术方案

索引遍历工程根目录维护的源码、资源、文档、工具与配置文件，包括 Assets、Packages、ProjectSettings、Docs、Tools 及其它工程目录；忽略 Unity `.meta` 展示节点、缓存/构建输出、助手私有状态、链接与根目录自动生成的工程文件。所有符合范围的文件均建立节点，包括孤立节点和不能解析内部内容的二进制资源。以规范项目相对路径及稳定符号标识节点；C# 类型声明和引用仅分析 `.cs`，Lua/脚本等作为代码文件节点保留，不冒充已完成语义解析。资源图用 `.meta` 中的 GUID 建立资源身份，并从可读 Unity 序列化文件建立引用关系。状态明确返回覆盖目录、各类文件数、孤立节点和排除范围，扫描只读。

图谱快照保存在 `.karolina/state/project-graph.json`，仅在用户请求时重建。构建时通过状态端点提供实际扫描进度、跳过数、索引时间、错误和容量限制；状态写入原子替换。符号/引用无法唯一识别时不猜边，二进制、过大文件和无法读取的文件记录为跳过信息。资源引用边仅表示文件引用，不表示运行时加载或语义依赖。

UI 默认只展示一张全量3D图，包含成功快照中的全部节点与关系。节点具有实际三维坐标，使用 WebGL 透视相机、深度测试与球形点精灵绘制。按真实引用关系聚集文件：声明边连接的文件及其类型相邻，强关联文件形成邻近引用群，群之间亦按联系排布；无已解析跨文件关系的节点分散到三维外围。禁止以文件夹、路径相似度或目录层级分组。引用群只是阅读布局，不等于人工架构模块，不新增事实边、不折叠或替代真实节点。布局采用稳定顺序的加权模块度分群、三维局部网格排斥与弹簧排布，在Web Worker中计算；完整关系数据继续供Agent随机查询，与几何布局分离。

点击图中节点、搜索结果或关联项仅更新右侧详情、强调关联，不重建为局部图，不改变已有视野；只有“定位选中”或“适应全图”等显式操作移动相机。鼠标左键拖动视野中心，右键或 Shift＋左键旋转，滚轮沿视线缩放，支持重置方向。搜索和类型筛选只作用于定位列表，不裁剪总图。跨群背景线淡化、选中关联强调；节点标签按缩放与选中优先级显示并避让，不以标签数量冒充节点数量。视锥和深度遮挡只影响显示，底层仍全量载入。不同代码和资源类型有图例。

节点保留工程相对路径，供Agent检索、文件访问与取证；人工界面的节点标签、搜索结果、悬停和详情不展示目录、目录分区或文件夹路径。引用依据用文件名、行号、关系说明及可信度展示，完整路径仍在原始数据与Agent返回中。资料附带工程根路径及索引时间，提醒Agent核对真实文件。

Karolina 提供供 Agent 主动调用的只读 MCP 查询：索引状态、节点搜索、上下游邻域、关联路径与可能影响范围；在 Codex 对话中通过局部会话配置注册，不要求人工先选图谱节点，不替换既有 Unity 工具。查询返回规范路径、关系依据、可信度、索引时间以及截断/深度边界。UI 与工具共用同一份快照和查询实现。MCP不允许写入文件、自动审批或自动运行索引。

关系依据包括文件路径、行号及声明/唯一类型名/GUID字段来源。代码文本解析与启发式引用明确标记，不宣称编译器语义证明；资源引用不推断二进制内部结构。观察工程事实源变动并在启动时核对文件清单，发生变动或无法核对时提示索引过期，仍由用户决定刷新。文件长度/修改时间一致不证明语义完整或内容未被等长改写。

## 边界情况

工程不是 Unity 项目、目录不存在或无可索引内容时提供可读状态。遇到重解析点/链接目录时拒绝穿越并将风险显式列出；扫描容量达到边界时停止而非静默返回不完整“完整图谱”。外部文件在扫描中变化时保留错误/过期状态并允许重建。缺失 `.meta`、重复 GUID、重复短类型名不会推断确定关系。`.meta` 仅内部解析身份，不在图谱列表或审批中显示。

图谱信息不修改、批准或归属文件，也不能证明 Agent 作者、资源运行表现或测试通过。旧索引在重建失败时保留，但必须显示上次成功时间及失败状态。

## 验收条件

- C# 文件和类型可被检索，文件包含关系与可唯一识别的类型引用可浏览。
- 资源 GUID 引用能在互相引用的可读 Unity 资源之间建立关系；脚本 GUID 能连到脚本节点。
- 搜索无结果、重复 GUID、无法解析的关系、二进制文件、链接目录、取消/失败和超量均显示真实状态，不生成臆测边。
- 重新索引期间 UI 可读取进度；失败后保留最近成功快照且显示其时间。
- 从节点加入对话资料仅添加选定上下文，不改审批或执行计划。
- 不修改 Unity 资产，不要求截图验收。
- 全量节点/边数量与成功快照一致，孤立、二进制以及 Docs/Tools/根目录文件可定位；点击只显示详情，图谱和视野不被替换。
- 左键平移、右键或 Shift＋左键旋转、滚轮缩放、适应全图和显式定位可操作；前后节点重叠时选取最前方可见节点，点击不改变相机。
- 跨目录强关联文件能够聚集，文件与声明类型相邻；全部原始节点与关系保留，布局不添加事实边。布局计算不阻塞主界面，同一快照使用稳定输入顺序产生同一几何结果。
- 保持节点身份与关系不变时，修改文件夹、路径和标题不能改变三维位置；页面不出现目录分区或文件夹信息，Agent仍能取得完整路径。
- WebGL不可用、布局线程失败或上下文丢失明确显示原因，并允许重试；错误不阻止搜索、其他页面输入或已有只读查询。
- Codex 可主动发现并调用只读图谱工具，无需先手动加入资料；截断和过期不能显示成完整结果。

## 附录

索引主键由节点类型和规范化路径/符号名确定，边由起点、关系、终点去重并稳定排序。索引文件包含 schemaVersion、规范化工程根路径、创建时间、遍历统计、错误和节点/边；版本不兼容时拒绝按新格式读取并提供重建入口。
