# Agent 任务验证与有限修复闭环

## 目标实现

执行任务时，Agent 先定位适用的机器验证，再运行、读取真实回执并按设置允许的轮数修复失败项后重跑。Karolina 清楚呈现 Agent 当前活动、工具调用、验证结论、失败原因和限制；完成后仍需人工审阅任务变更。关闭程序后任务审批、运行记录和已有工具回执可恢复。

## 技术方案

执行上下文携带所选计划的验收/测试要求、工程规则和当前统一设置。Agent 在同一 Codex 任务中按“调查→实现→运行相关验证→读取真实失败→有限修复与复测→总结”的顺序工作；默认修复轮数由用户设置且有上限。Karolina 根据 Codex app-server 的实际 `item/started` / `item/completed` / `turn/*` 通知派生进度，不通过解析 Agent 的自然语言猜测状态。命令和 MCP 回执保留在现有任务运行记录，任务审批继续绑定既有冻结文件版本和人工决策。

### 对话中的进度与思考摘要

讨论需求、制定计划和执行任务均显示“本轮进度”：准备发送、理解目标、查阅资料、安排步骤、执行操作/机器检查、整理说明及真实完成/失败/停止。活动由匹配当前thread/turn的回执生成；操作类型是活动分类，不据此宣称修改、测试或验收成功。不显示伪造百分比，无新回执时明确表示等待。原始CLI命令、工具输出和协议JSON仅保存在诊断记录，日常对话不逐条展示；真正需要批准的操作保留可主动展开的详情。

在保留用户选择的模型和档位时请求Codex公开reasoning summary，展示summary字段和summary通知，不展示私有reasoning content/textDelta。模型未提供摘要时明确说明“未提供”，不生成占位思考。Agent说明使用简体中文交代理解的目标、依据摘要和下一步，用户测试既有功能时先明确参考计划中的验收条目；资料不足时询问。此说明与工具事实分别呈现，不能将模型文字当成机器通过证明。

历史对话从Harness保存的公开summary恢复。当前进度可从RunRecord恢复阶段、公开摘要和步骤；不同聊天、旧轮次以及完成后的迟到活动不能覆盖当前反馈。新对话不显示旧进度。完整命令回执继续供诊断和任务证据核对，原有审批生命周期保持。

本轮结束后只读补取该轮历史中的公开摘要，不追加模型对话或提高档位。空摘要不能清除已收到的有效摘要；历史读取失败在摘要区说明原因，保留实时回执，不将读取失败误称为模型没有提供摘要。

机器验证限于计划明确的 Unity EditMode/PlayMode 测试、既有可调用检查或 Codex 当前可用工具。只有实际收到成功终态和测试计数时才显示通过。Unity 未连接、计划未明确测试、工具未配置、测试返回非终态或请求需要构建时，显示待处理/未运行及原因；不得自动触发正式 Unity 构建。程序自身只提供 Agent 的有界执行规则提示与真实工具过程/回执记录；对 Agent 外部 Harness 的执行能力不得伪装为 Karolina 自己已完成验证。

修复迭代在原任务和对话上下文中进行，失败输入包含原始工具错误、测试标识和当前轮次；不得创建丢失关联的新审批任务。达到上限仍失败时任务进入等待人工处理，保留失败文件和记录，不批准、不回滚、不重试隐藏的额外轮次。用户审批退回是独立的人工再执行轮次，保持现有审批生命周期。

## 边界情况

Codex 未连接、连接中断、进程退出、停止、Unity 不在线、没有真实测试计划、工具拒绝/超时、测试结果缺字段或无效、验证期间代码发生变化时，必须显示准确阶段和原因。未经确认不能将空回执或模型文字当作测试成功。进度更新不得阻塞释放 Codex 任务锁，审批保存失败必须可见。旧运行记录缺少新进度字段时按“历史记录/无可恢复进度”读取。

统一设置中的轮数是 Agent 指令约束，不能作为对不受 Karolina 控制的外部 Harness 的安全沙箱；无法由 Codex 事件证明的轮次限制须在界面和文档中明确。

## 验收条件

- 正常执行能显示开始、真实文件/命令/MCP 工具事件、验证调用和结束状态，事件说明对应真实 Codex 回执。
- 测试错误会留在同一任务上下文内供 Agent 按配置进行有限修复；实际失败回执不会显示为通过。
- Unity 不在线/验证未执行/达到修复上限时，显示原因并保持任务未批准。
- 完全关闭后重开，待审批任务、摘要、运行结果和已有进度记录仍可读取；旧记录兼容。
- 原任务整体/单文件审批、人工退回和批准的版本约束保持。
- 正式构建不自动启动，Agent 不代替人工验收；不使用截图验收。
- 在讨论需求中默认勾选PLAN-KAR-011及其关联文件仍能发送；Agent理解所选测试目标，日常界面显示可读活动及公开摘要，CLI和私有推理不展示。

## 附录

进度阶段由事件类型与真实状态映射，未知工具仅显示“工具操作”，完整工具名在诊断中保留。公开摘要是否返回由模型/Harness决定；请求summary不升级模型或思考档位。设置修复轮数建议限制为 0–3，默认 1；每项修复必须回到真实工具重验。
