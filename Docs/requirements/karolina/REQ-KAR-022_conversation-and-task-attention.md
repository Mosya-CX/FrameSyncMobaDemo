# 对话查找与任务待处理入口

## 目标实现

对话可按标题与用户原话检索、手动重命名且重启保留。状态栏汇总跨对话权限申请、待审批任务及验证阻塞；只有点击才定位。用户可查看当前任务授权并提前撤销，相关轮次明确停止，其他任务不受影响。

## 技术方案

本地聊天索引仅收录本工程RunRecord中的用户原输入，异步缓存，历史无原输入记录时提示覆盖范围。重命名只更新本工程聊天列表，不覆盖Codex历史。待处理API聚合权限、审批及验证记录，UI弹出精简面板。授权撤销用人工API，绑定工程、thread/run，复用既有取消与进程回收流程；Agent MCP不能批准或撤销授权。

## 边界情况

删除仍逐次确认，运行中不可删除。搜索命中不自动跳转；无记录不能假装全文覆盖。重复撤销、到期、原轮次结束均幂等；授权回收失败明确报错且关闭受影响执行环境。

## 验收条件

按用户原话命中标题不包含关键字的对话，重命名后重启保留；状态栏计数与原始记录一致，点击定位且后台不跳页。撤销当前授权后写入口拒绝、执行停止，其他对话不受影响。
