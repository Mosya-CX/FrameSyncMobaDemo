# 方法取证与检索效率

## 目标实现

Agent 能针对已提供 C# 源文件按方法名读取真实实现，不自行计算长方法的分段行号；明确本轮已核对范围和剩余分页。按问题类型优先提供必要代码或约束文档，减少重复资料。用户能在折叠摘要看到失败、拒绝和重复读取数量，以及资料/图谱索引时间、过期和覆盖不足。

## 技术方案

新增只读 project_read_method，输入已提供来源 ID 或文件路径、方法名、可选声明行及分页号。宿主重新核对当前来源权限和正文指纹，用保守 C# 词法扫描定位完整声明与方法体；重载无法唯一确定时列声明行并要求明确选择。每页仍限60行、6000字符，有界分页，不自动读取整个文件，不猜动态关系。未支持语法明确失败，可退回已有行范围工具。

本轮已核对范围按路径、正文/元数据指纹及行范围登记；相同范围重读仍核对真实文件后提示重复，不把过期记录当当前证据。提供有界 project_evidence_status 给模型查询，不新增外部模型。直接行读取继续保留。

初始上下文按实现流程、规则/目标或验证类问题选择优先资料；有代码直接命中时优先入口、必要调用，再补明确配置/测试，保留必要规则及结构化状态。预算有界，未提供明确标记，不降低历史和读取边界。

计数按当前轮次登记成功、失败/拒绝和重复取证；错误消息不用来推断是否通过。对话资料摘要显示实时索引就绪/重建/过期及遗漏计数，详情折叠；旧问答的引用身份不随新索引刷新冒充当前。

## 边界情况

多对话及旧凭据隔离；撤销读取、文件改变、方法重载/抽象声明、字符串及注释、表达式方法、长行、分页越界均有真实结果。方法定位是词法分析，不承诺编译器语义或所有复杂语法。资料不构成执行指令，Unity 和扩展工具权限仍各自管理。

## 验收条件

隔离夹具覆盖分段、重载、注释/字符串、过期及权限撤销、重复提示和轮次隔离。真实工程问答扩充不同类型题目，对比有/无 RAG 的用量、失败调用、耗时及准确原文，保留全部失败。提速省量仅按实测报告，不承诺每题胜出。原生输入用 Windows 事件，不截图。

## 附录

承接 REQ-KAR-023 的检索与取证合同，保持最多60行/6000字符、已提供文件及历史过滤；连接联调遵循 REQ-KAR-024。无新增依赖、隐蔽模型或 Unity 实现修改。

## 需求演进

### 2026-10-09：批准效率与连接联调批次

用户批准两个核心项（真实 Unity/原生窗口联调，减少无效 RAG 读取）及两个配套项（失败调用计数，索引覆盖提示）。本需求限定方法取证与检索效率，旧连接计划不自动关闭。
