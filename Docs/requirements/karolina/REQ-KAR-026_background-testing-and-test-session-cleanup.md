# 后台测试与测试对话清理

## 目标实现

自动化验证结束后删除由本次测试创建的对话及其 Codex 本地会话文件；旧测试记录通过准确来源清单清理。默认界面测试不占用用户的系统鼠标、键盘焦点或托盘，不切换用户目标工程。

## 技术方案

- 测试创建独立临时工程时登记来源标记、规范根路径和准确线程 ID。测试宿主确认退出后，在 finally 中使用 Codex 官方 thread/delete 永久删除；thread/archive 只是归档，不能满足测试清理。
- 删除前读取归档及非归档线程关系。存在派生线程、固定标记、工程不符、仍运行、读取失败或关系清单不完整时保留记录并报告。不得写 Codex 数据库或根据标题猜测测试所有权。
- Karolina 的运行证据只删除与准确临时工程及线程关联的独立 runs/{id} 文件夹。校验真实路径、来源和无目录重定向；正常用户的对话、文档和审批记录保留。
- 默认后台检查启动实际 WinForms/WebView2，但测试窗口位于桌面可见范围外，不激活、不显示托盘，使用独立 WebView2 资料目录，通过 CDP 派发渲染器输入事件。只读观察前台窗口，检测测试宿主是否抢占焦点。
- 后台入口须同时提供显式测试开关、环境标记和独立临时工程登记，不接受真实项目。真实 Windows 输入脚本必须带 --interactive 才可启动。

## 边界情况

- ephemeral 的真实 RAG 比较线程本来不持久化，不伪造永久删除成功；保留无正文的计时、token 和通过失败统计。
- 停止证明必须是本测试宿主的认证 shutdown 成功回执加正常退出，或确切自建进程树被停止并收到退出事件。父进程自行异常退出时，不能推断模型子进程已停止，不追杀无法确认来源的进程。
- 清理失败仍保留失败记录和准确重试清单，测试进程报告失败，不因测试主体成功掩盖清理失败。
- 后台输入验证不等于 Windows 实体键盘、中文输入法、真实焦点或托盘验证；这些须另行显式交互测试或未来隔离会话验证。本批不安装虚拟机或依赖，不截图。
- 用户正常删除对话的既有归档行为不改为永久删除。历史遗留且无法取证的记录不自动认领。

## 验收条件

1. 确认的旧测试线程永久删除后，官方读取/只读数据库及原 rollout 路径均不再保留对应会话；非目标线程仍保留。
2. 自动清理覆盖真实模型测试、权限/并行测试和新后台输入测试的退出路径；失败清理明确报告。
3. 实际后台 WebView2 可以输入中文、发送夹具对话、保存文档、填写审批；前台观察没有发现测试宿主占用，默认目标工程未改变。
4. 未显式开启时真实鼠标测试拒绝运行，不调用 Windows 输入辅助脚本。
