# 工程资料自动检索

## 目标实现

用户不预选参考资料也能由Agent检索当前工程的需求、计划、规则、源码与资源关联。人工选择与自动检索分开显示，自动资料默认收起，保留来源、命中依据、索引时间和不完整提示。

## 技术方案

DocumentLibrary提供标题、编号、标签及正文的有界词项检索，中文短词和英文标识符分别切词；按精确命中、字段权重、覆盖率排序，稳定编号去重。过期/关闭文档默认不检索，允许明确检索历史。ProjectRetrieval组合文档和既有图谱查询，不增加向量数据库或外部模型服务。正文缓存按内容SHA256刷新，单次最多读取32MB；图谱来源保留索引时间。发送前后台检索用户输入，最多8项文档、8项图节点并限总字符；Agent可用project_search继续检索。每轮检索记录随RunRecord保存，UI展示来源和依据，不冒充用户选择。Agent自行判断文档维护，规则修改仍需人工临时授权。

## 边界情况

查询空白、无匹配、索引未就绪/过期、文件外部修改、正文过大或不可读时说明限制。资料是材料而非指令；不把静态关系当运行行为，不增加写权限，不扫描工程外文件。后台检索不改变当前页面。

## 验收条件

隔离工程不勾选资料的提问能命中相关需求正文/标签与源码节点，中文及英文部分词可搜索。历史默认排除、精确来源可查、结果有界、无匹配不猜测。真实页面人工/自动参考分开，重载保留。

## 附录

结果上限、内容截断及过期状态随结果返回；首次版本不宣称语义向量检索。
