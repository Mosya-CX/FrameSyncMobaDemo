## 准备

复用DocumentLibrary、ProjectGraphService、EvidenceStore、TaskReviewStore、ScopedSandbox、PermissionRequestBroker和TemporaryAuthorizationStore。Core不依赖Desktop或Unity；不增加依赖。产品文档只放关联工程Docs；保护原工作区和三狼内容，catalog.activePlan保留PLAN-WOLF-165，本批用本计划明确承接。

## 执行

1. Core ProjectRetrieval完成词项检索与有界来源聚合，发送前异步执行，RunRecord持久化AutoReferences；MCP支持主动补查。
2. Core TaskVerificationStore独立持久化check/attempt状态，执行器在Desktop；命令只读沙箱，Unity验证限定tests-run。输入哈希防止过期结果复用，首次失败后的受控写入计修复轮，达到上限拒绝；外部工具边界明确。
3. Core ConversationSearch读取本工程用户原话索引；人工重命名原子保存聊天列表。
4. Desktop待处理与授权API聚合跨对话情况，前端仅点击时导航；撤销绑定授权的轮次，取消自有操作并回收进程。
5. 前端默认收起自动资料与验证明细；保持现有美术、动效、输入、3D图谱和页面稳定。

## 校正

## 验收（人工）

## 关闭

本机桌面Codex附带0.162.0-alpha.2，Karolina原先按文件时间自动选中该版本。真实thread/start在应用禁止读取规则时，因已运行node_repl.exe的运行时ACL刷新失败而中断；没有通过手改该可执行文件、关闭桌面Codex或放宽权限规避。官方npm稳定版0.160.1在同一登录与全局配置下通过同样的原生权限验证。

Karolina现独立管理已验证版本，路径为本机LOCALAPPDATA/Karolina/codex-runtime/0.160.1，首次连接下载Windows x64对应的官方OpenAI Codex包（不是新增Unity包或.NET依赖）。固定下载地址及SHA512，六个核心文件另校验SHA256，不追随alpha、不失败回退到更宽权限。保留显式开发运行时覆盖，不复制凭据。当前已验证平台为Windows x64；更新固定版本必须重新做本计划的原生权限及实际模型联调。

### 新对话历史读取校正

人工反馈：新对话发送后弹出原生thread/read的空rollout错误，但模型仍继续完成回答。源码确认前端在chat/send成功后立即调用loadChat读取历史，可能早于Codex会话文件落盘。这次失败属于历史加载，不能据此将已提交的执行任务判为失败或重发。

修复后，新对话使用已有用户消息与实时事件，不再无条件立即读取历史；发送回执之前到达的事件暂存，确认身份后只重放当前对话的事件。事件缓存设上限，必要补读不会将用户从其它页面切走。真正打开历史、完成后补读公开摘要和停止时核对终态统一使用CodexThreadHistory；仅对原生错误码-32603且明确为会话metadata对应rollout暂空的错误短暂重读，最多6次、累计等待3秒，支持取消。损坏、缺失、其它RPC失败不转换成空历史，也不重试任务执行。

新增5项定向检查覆盖重读范围、次数上限、真实失败保留、错误签名及取消；相关对话反馈11项、前端7项回归通过。ChatHistoryLiveChecks使用真实桌面宿主/浏览器与协议夹具，注入前两次历史暂空、发送回执延迟和早到回答：确认首次发送零历史请求、回答完整且不串对话、暂空后成功载入、真实损坏返回失败、草稿保留、页面错误0。TaskAssistanceLiveChecks继续验证真实只读沙箱与任务闭环，通过。未为本次时序修复调用付费模型；协议夹具不计为原生Codex行为验收。
