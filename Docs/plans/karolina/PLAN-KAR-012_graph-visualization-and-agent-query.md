## 实施细节

### 数据、查询与边界

Core 唯一持有图谱快照；节点与边附带有界关系依据（文件、行号、文本/GUID来源、可信度）。旧版索引保持可读，缺少依据时提示刷新，不编造补齐。Schema3快照附带文件长度与修改时间清单、覆盖与排除统计；同一工程文件策略扫描和观察维护文件，包括源码、资源、Docs、Tools、.agents及根目录文件，启动核对清单。索引失败保留旧结果。时效检查不是内容哈希或编译器语义证明。

查询从成功快照建立节点及入边/出边字典。邻域使用BFS，最多4层、500节点、1000边；路径最多12层、5000访问节点；返回截断和深度限制。影响范围沿入边与声明关系扩展，不宣称完整运行时覆盖。Overview返回所有节点及轻量关系，不沿用邻域限额；依据详情按选择读取。

Desktop 提供会话校验的本机只读MCP：status、search、neighbors、path、impact。Codex新建/恢复对话时通过局部会话配置注册，保留Unity MCP和全局账号配置。MCP不自动写入、重建、修改或审批资源。UI与MCP共用Core服务。节点保留路径供Agent访问，展示层不显示文件夹。

### 关联布局

纯布局模块只读取节点身份、类型及既有边，不读取路径和标题。仅显式声明边使文件与声明类型形成几何锚点，原始节点仍全部放置和绘制，不能因路径相同而合并。GUID边权3、继承/实现2、启发式类型引用0.6、其他边1，仅影响布局。

稳定哈希排序、加权模块度局部移动每层最多24遍、最多4层聚合，分辨率1.3；拆分群内不连通部分。群内和群间都使用三维初始化、加权弹簧及三维局部网格排斥，不建立目录分区。无跨文件关系的锚点在外围球面分散，类型围绕文件放置。布局为一次计算，不持续晃动；返回XYZ、包围半径及内部关联群标识，不新增事实边、不生成目录节点。

Web Worker承担计算；结果消息与当前Worker实例和页面生命周期核对。替换或销毁视图终止旧Worker、取消动画帧、断开ResizeObserver和输入事件，迟到结果不能覆盖新视图。布局错误显示并提供重试，不阻塞其他页面。

### 三维显示与交互

相机模块独立计算视图基向量、45度透视、投影、球形全图适应、旋转、平移、缩放和点击拾取。WebGL模块维护XYZ缓冲、节点颜色和全部边顶点，使用深度测试和球形点精灵，未添加三维引擎依赖。切换绘制程序时同步启用/禁用顶点属性，避免缓冲长度不匹配。颜色和选中关系由视图传入，渲染器不调用API或持有文档状态。

左键拖动沿相机右/上方向移动中心；右键或Shift＋左键改变朝向；滚轮改变相机距离。点击图中节点、搜索结果或关联项只更新详情和高亮，保持相机六个字段不变；只有“定位选中”“适应全图”等显式操作改变视野。选取前方可见节点，CPU投影与GPU使用相同近/远裁剪。背景线淡化、选中边强调，名称标签按优先级避让，目录信息不显示。标签和屏幕裁剪不改变全量数据。

仅在交互、大小或主题改变时请求一帧，不持续空转。WebGL不可用、上下文丢失和Worker错误明确显示；可重试，恢复图形上下文时保留相机和选中节点。页面保留图例、全量计数和键盘方向/+/-操作。

## 机器测试与 Agent 审查设计

- 数据/查询：文件→类型→基类、Prefab→脚本、循环、多路径、未知ID、方向、节点/边/深度截断，重复GUID、文本解析边界、旧/损坏快照、索引失败保留与时效监控。
- 三维布局：4000节点不丢失、XYZ有限且具有实际深度、声明类型邻近、密集关联靠近、输入顺序反转仍稳定；身份和边不变时改全部目录、路径、标题，位置必须完全一致；无声明边时同路径不能合并。检查空图、自引用、孤立节点和空间重叠。
- 相机：近大远小、前/后裁剪、绕轴旋转、视图平面平移、全图适应、滚轮缩放、重叠点优先选择前方。
- 浏览器：节点缓冲N、边缓冲2E等于Overview；初始全图视锥包含全部节点，真实左右键、滚轮及小窗口操作；图/搜索/关系点击前后同一Canvas和相机不变；目录信息不显示，依据和资料入口保留，输入/主题/自动连接不回归。
- 生命周期：延迟Worker期间能输入与离页返回，Worker错误可见；WebGL不可用时其他UI可用、恢复后可重试；实际上下文丢失/恢复保留相机和选中，缓冲仍完整。
- Windows原生：实际交付EXE的WebView2中使用鼠标、滚轮、SendInput中文键盘验证，不以DOM设置值替代输入。
- 独立只读审查：真实XYZ/透视/深度、GPU缓冲全量、路径不参与布局、点击边界及Worker/事件/GPU生命周期；已有MCP鉴权、容量边界保持。

禁止截图验收。机器测试不代替人工阅读体验。

## 人工验收

打开工程图谱：确认只看到一张三维全量图，无文件夹区域或目录标签；旋转、平移、缩放观察关联节点。点击节点与关联项看详情，视野保持；按需点“定位选中”。通过AI对话检查Agent能主动查关系及真实路径。用户确认空间组织、文字清晰度和操作体验后才关闭。

## 恢复与限制

仅修改Karolina源码和配套文档；Unity工程是只读数据源，不改源码、资源或三狼工作。索引失败保留最近成功快照。受限文本解析不覆盖反射、动态加载、完整调用图或二进制内部结构。三维投影仍可能遮挡节点和产生长边，可通过旋转/缩放及搜索定位查看；保证数据完整不等于保证任何视角都清晰。WebGL不可用时显示真实错误，不伪装成3D；人工详情和Agent查询仍可使用。
