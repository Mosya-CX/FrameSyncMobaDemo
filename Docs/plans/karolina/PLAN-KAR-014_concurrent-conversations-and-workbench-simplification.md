## 准备

检查现有单例执行字段、全工程写锁、任务审批单任务限制、MCP 会话令牌与 CLI 原生 sandbox。清点 artifacts 的生成内容、临时 Docs 副本、研究资料和诊断脚本，正式启动目录 current 保留。当前三狼及其文档不修改，catalog.activePlan 保持 PLAN-WOLF-165。

## 执行

1. 删除产品的 Karolina 仓库探测、其它仓库发布与外部计划批准入口；重试也校验当前目标工程。推送面板只常显额外规则和提交推送，运行/失败时显示必要操作，结果详情折叠。
2. 空对话隐藏状态栏，发送/有历史内容时显示。摘要保留标题和正文，通过样式区分未知外文，去掉重复标签与原文开关。切换对话保存草稿，列表显示运行标识。
3. 每对话组合独立 CodexConnection 和运行状态，共享目标工程的文档、图谱、设置与线程安全审批服务。主宿主聚合事件和列表，按 threadId 查询当前状态与停止对象。
4. Core 目录协调器按规范相对路径和前缀重叠判断互斥；TryAcquire 冲突立即返回。实际写操作持有租约，文件活动刷新时间，定时取消空闲操作。取消后须等操作及自有进程树结束才能释放。
5. 原生会话只读；会话 MCP 提供 SHA256 比较后的文本写入和按目录编译权限的单次 sandbox 命令。精确写入保存逐文件取证；命令期间变化不冒充作者证明。任务允许并发创建，来源和审批版本继续独立核对。
6. 将可重复运行的验证保存在 Tests；临时工程和日志使用系统临时目录。移除 artifacts/current 外无运行需要的生成内容，产品文档只留关联工程 Docs。

## 测试（机器与 Agent）

目录协调器覆盖不冲突并行、前缀与大小写冲突、busy 非阻塞、空闲取消不提前释放、清理后再次获得、取消/失败后释放。真实 sandbox 操作验证目标文件可写、旁路写拒绝。真实 Codex 低成本模型在两个临时计划中分别调用文件工具，并行运行、独立状态和停止。实际加载页面检查空状态、摘要样式、精简推送、连接、图标与输入。不截图；高风险并发由独立只读审查复核。

## 校正

修复定向检查与审查发现的生命周期、令牌、来源取证或清理问题，再执行相关检查。不能以协作提示替代文件权限，也不能把 HTTP 取消当作外部 Unity 操作已经停止。

## 验收（人工）

用户检查只显示当前工程的轻量推送面板、空对话不显示右侧状态、多个对话同时运行和切换、忙目录转做其它工作的反馈、占用自动回收提示、可编辑配置资源及干净 artifacts。机器检查通过后保持验收，等待人工意见。

## 关闭

人工验收通过后关闭本计划，后续改造新建计划。
