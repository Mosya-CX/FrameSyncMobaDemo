## Agent 测试设计

方法工具每页不超过60行/6000字符；未知方法、重载无行号、非法分页、受限/变更来源不能返回正文。相同范围再读提示重复；文件变化拒绝旧取证，重检后新指纹独立计数。普通文档不能利用方法入口跨章节或读历史。上下文对流程题保留入口及关联，对约束题保留规则，对状态题保留元数据及验证。至少四种工程题有/无 RAG 对照，低成本当前 Codex 模型，DeepSeek 默认关闭，禁写入/Unity操作；原文引用逐条核对，不能用关键字评分代替正确性审查。

## 实际改动与数据流

1. `project_read_method` 使用本轮已提供的来源身份，在宿主重新验证权限、正文与元数据指纹。宿主扫描该 C# 文件的方法范围，只返回当前有界页；返回声明行、结束行、分页总数和下一页。没有唯一重载时要求声明行，不返回猜测内容；复杂语法保留行读取退路。
2. `KnowledgeSession` 按任务轮次与凭据登记核对过的路径、指纹、行范围，最多保留128条，状态工具最多返回32条核对记录与48条已提供来源。状态查询重新检查当前文件，不把预览或过期资料标成已核对。范围已读不会阻止再次读取，但返回重复标记并计数。
3. `KnowledgeEvidence` 对实现题优先入口和调用线索，减少同一文档的重复切片，每个文件只提供一次缩短的声明导航；约束题保留文档。此处为启发式预算分配，不是可靠语义分类器，未提供资料明确提示。
4. Desktop 在有效当前轮次登记工具成功、失败、拒绝与重复读取；旧凭据不能污染新一轮。对话右侧的“检索与用量”“当前索引”默认折叠，分别展示真实调用与当前索引信息，刷新不改页面。拒绝是失败的子集，重复读取包含在成功读取内；不统计其它原生命令，也不换算费用。
